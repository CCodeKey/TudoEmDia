# REQUISITOS NÃO FUNCIONAIS

| Número | Nome | Descrição |
| ----- | ----- | ----- |
| RNF01  | Segurança de acesso | O sistema deverá permitir o acesso às funcionalidades e aos dados de uma empresa somente a usuários autenticados e autorizados, respeitando seus respectivos perfis de permissão. |
| RNF02 | Proteção de credenciais | O sistema deverá armazenar as senhas dos usuários de forma segura, utilizando mecanismos de hash apropriados, sem armazená-las em texto puro. |
| RNF03 | Privacidade dos dados | O sistema deverá proteger os dados pessoais e empresariais dos usuários contra acesso, divulgação ou alteração não autorizados. |
| RNF04 | Desempenho | O sistema deverá responder às operações comuns de consulta, cadastro e edição em até 3 segundos, considerando condições normais de utilização. |
| RNF05 | Disponibilidade | O sistema deverá estar disponível para utilização pela internet, exceto durante manutenções programadas ou em situações de indisponibilidade de infraestrutura externa. |
| RNF06 | Usabilidade | O sistema deverá apresentar uma interface intuitiva, com navegação consistente e identificação clara das funcionalidades, facilitando sua utilização por pessoas sem conhecimentos técnicos avançados. |
| RNF07 | Responsividade | O sistema deverá adaptar sua interface a diferentes tamanhos de tela, incluindo computadores, tablets e dispositivos móveis. |
| RNF08 | Compatibilidade | O sistema deverá funcionar nas versões estáveis recentes dos principais navegadores web, incluindo Google Chrome, Mozilla Firefox e Microsoft Edge. |
| RNF09 | Integridade dos dados | O sistema deverá preservar a consistência das informações financeiras e empresariais, evitando registros inválidos ou inconsistentes durante as operações. |
| RNF10 | Confiabilidade das notificações | O sistema deverá processar os alertas por e-mail conforme os prazos definidos nos requisitos funcionais, evitando o envio duplicado de um mesmo alerta para o mesmo destinatário e vencimento. |
| RNF11 | Manutenibilidade | O sistema deverá ser desenvolvido com código organizado e documentado, facilitando a correção de erros, a manutenção e a evolução das funcionalidades. |
| RNF12 | Formato dos relatórios exportados | O sistema deverá gerar os relatórios exportados em formato PDF, preservando a legibilidade das informações. |
| RNF13 | Proteção na comunicação | O sistema deverá utilizar comunicação criptografada por HTTPS quando disponibilizado em ambiente de produção pela internet. |
| RNF14 | Conformidade com a legislação | O sistema deverá tratar os dados pessoais em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD), observando os princípios e as obrigações aplicáveis. |
