# REQUISITOS FUNCIONAIS

| Número | Nome | Descrição |
| ----- | ----- | ----- |
| RF01  | Cadastrar usuário | O sistema deverá permitir que uma pessoa crie uma conta informando seus dados de cadastro. |
| RF02 | Autenticar usuário | O sistema deverá permitir que um usuário cadastrado acesse sua conta por meio de suas credenciais. |
| RF03 | Cadastrar empresa | O sistema deverá permitir que um usuário autenticado cadastre uma empresa e passe a administrá-la como proprietário. |
| RF04 | Convidar usuários  | O sistema deverá permitir que o proprietário convide outros usuários para acessar uma empresa.  |
| RF05 | Gerenciamento de acesso | O sistema deverá permitir que o proprietário consulte os usuários vinculados à empresa e gerencie seus acessos |
| RF06 | Controle de permissões  | O sistema deverá disponibilizar funcionalidades de acordo com o perfil do usuário: proprietário, financeiro ou contador. |
| RF07 | Cadastro de obrigações  | O sistema deverá permitir o cadastro de contas e obrigações, incluindo descrição, valor, categoria, data de vencimento e anexos.  |
| RF08 | Consulta de obrigações  | O sistema deverá permitir a consulta das obrigações cadastradas, com informações sobre seus valores, categorias, vencimentos e situações.  |
| RF09 | Edição de obrigações  | O sistema deverá permitir a edição dos dados de obrigações cadastradas, conforme as permissões do usuário.  |
| RF10 | Exclusão de obrigações  | O sistema deverá permitir a exclusão de obrigações cadastradas, conforme as permissões do usuário.  |
| RF11 | Classificação de obrigações  | O sistema deverá permitir a organização das obrigações por categorias.  |
| RF12 | Controle de situação  | O sistema deverá identificar as obrigações como pendentes, pagas ou vencidas, conforme suas datas e registros de pagamento.  |
| RF13 | Cadastro de documentos  | O sistema deverá permitir o armazenamento de documentos empresariais, incluindo descrição, categoria e arquivo.  |
| RF14 | Consulta de documentos  | O sistema deverá permitir a consulta dos documentos cadastrados e o acesso aos arquivos conforme as permissões do usuário.  |
| RF15 | Edição e exclusão de documentos  | O sistema deverá permitir a edição das informações e a exclusão dos documentos cadastrados, conforme as permissões do usuário.  |
| RF16 | Configuração de recorrência  | O sistema deverá permitir a configuração de obrigações recorrentes, com periodicidade mensal ou anual.  |
| RF17 | Geração de obrigações recorrentes  | O sistema deverá gerar novas ocorrências de obrigações conforme a periodicidade configurada.  |
| RF18 | Registro de pagamentos  | O sistema deverá permitir o registro de pagamentos de obrigações, incluindo a data em que foram realizados.  |
| RF19 | Histórico de pagamentos  | O sistema deverá disponibilizar o histórico de pagamentos realizados, incluindo a obrigação relacionada, a data e o usuário responsável pelo registro.  |
| RF20 | Configuração de alertas  | O sistema deverá permitir a definição das preferências de notificação por e-mail, conforme as regras estabelecidas para a empresa.  |
| RF21 | Envio de alertas de vencimento  | O sistema deverá enviar alertas por e-mail aos usuários destinatários antes do vencimento das obrigações, nos prazos de 7, 3 e 1 dia antes do vencimento e no dia do vencimento.  |
| RF22 | Visualização do painel  | O sistema deverá disponibilizar um painel com informações consolidadas sobre as obrigações da empresa.  |
| RF23 | Total a pagar  | O sistema deverá apresentar o total de obrigações a pagar no mês selecionado.  |
| RF24 | Visualização de obrigações vencidas  | O sistema deverá apresentar as obrigações que estejam vencidas e ainda não tenham sido pagas.  |
| RF25 | Gráficos por categoria  | O sistema deverá apresentar gráficos com a distribuição dos valores das obrigações por categoria.  |
| RF26 | Indicador de obrigações em dia  | O sistema deverá apresentar um indicador que permita acompanhar a situação das obrigações da empresa.  |
| RF27 | Exportação de relatórios  | O sistema deverá permitir a exportação das informações de obrigações e pagamentos. |
